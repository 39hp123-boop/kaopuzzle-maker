# かおパズルメーカー

子どもの顔写真をその場でスライドパズルにできる、親子向けの工作アプリです。

- 依存ライブラリなし・単一HTMLファイルのバニラJS
- 写真は端末内だけで処理し、どこにも送信・保存しません
- 6ピース/9ピース切り替え、タップ/ドラッグ操作、タイマー、完成演出(なまえ表示・紙吹雪)
- カメラ撮影(ガイド付き、インカメラ/アウトカメラ切り替え、端末標準カメラへのフォールバックあり)
- サウンド(Web Audio APIで合成、効果音ファイル不使用)

## ローカルで開く

`index.html` をブラウザで直接開くだけで動作します。

カメラ機能(`getUserMedia`)はブラウザの仕様上、`file://` や非HTTPS環境では動作しません。ローカルサーバー経由、またはHTTPSでホスティングした状態で確認してください。
